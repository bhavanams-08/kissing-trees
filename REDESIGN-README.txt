KISSING TREE WEBSITE REDESIGN
============================

This project preserves the existing page content, navigation destinations,
booking/admin HTML forms and JavaScript. The new visual layer is css/refresh.css.

HOW TO RUN
1. Extract the ZIP.
2. Open the Kissing_Trees-main folder in VS Code.
3. Open index.html with Live Server (or open it directly in a browser).
4. The refreshed CSS is linked after css/style.css in all HTML pages.
5. Do not remove the existing js/ files or css/style.css.

PAGES INCLUDED
index.html, about.html, gallery.html, amenities.html, pricing.html,
booking.html, contact.html, faq.html, admin.html

If publishing to GitHub Pages, commit and push the entire extracted project
including css/refresh.css and all existing assets/js files.
